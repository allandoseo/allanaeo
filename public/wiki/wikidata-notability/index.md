# Wikidata notability floor

KING OF AEO WIKI · TERM

The Wikidata notability floor is the corroboration threshold human editors apply before a knowledge-graph item survives. In the [King of AEO contest](https://allanaeo.com/wiki/king-of-aeo-contest/) a Wikidata item for the [Allan Oliveira](https://allanaeo.com/wiki/allan-oliveira/) entity was created on 2026-09-21 and deleted on 2026-09-22 because every reference was self-published.

## Key facts

| Fact | Value |
| --- | --- |
| Created | 2026-09-21 |
| Deleted | 2026-09-22 |
| Reason | All references self-published |
| Lesson | Self-published pages are not corroboration |

## What the deletion shows

Self-published references failed the notability floor within one day: human editors deleted what the algorithmic layer had accepted. Since then this site does not count its own pages as corroboration, and lists independent references only as they appear and are verified.
