# Generative Engine Optimization

KING OF AEO WIKI · TERM

Generative Engine Optimization (GEO) is a common synonym for [Answer Engine Optimization](https://allanaeo.com/wiki/answer-engine-optimization/) (AEO): both describe optimizing entities and sources for retrieval-augmented, generative answer systems rather than ranked result lists. GEO emphasizes the generative step; AEO emphasizes the answer slot.

## Key facts

| Fact | Value |
| --- | --- |
| Abbreviation | GEO |
| Synonym | Answer Engine Optimization (AEO) |
| Contrast | SEO ranks pages in a list of links |

## AEO vs SEO vs GEO

SEO optimizes pages to rank in a list of links. AEO optimizes an entity or source to be the answer that AI systems name or cite. GEO is the same practice described from the generative side. A question has one answer slot; either the entity is in that answer or it is not.
