King of AEO Citation Watch

The King of AEO citation watch measures which entities AI answer engines name for a fixed set of five prompts. Each weekly run replays the same prompts on Google AI Overview, ChatGPT, Perplexity and Gemini in the US and Brazil, logged out. Every answer is published here and in the raw CSV; the series starts with the first log, scheduled for 2026-10-05.

METHOD

  • Sessions: logged out, in a fresh incognito window per prompt, with no personalization.
  • Locale: US runs use the engine set to English with a United States location; BR runs use a Brazil location. The prompt text never changes between countries.
  • Date: every row carries the ISO date it was collected, shown in the table and in the CSV.
  • Recording: the answer's named entities are written down in the order the answer gave them, with a source note per row and a screenshot where available.

These are manual single observations, not aggregated sampling: one run per prompt, per engine, per country, per week. A single answer can vary between runs, and this log does not average that variance away — it records what one logged-out session saw on one date.
