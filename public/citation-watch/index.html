Methodology

How every King of AEO number on this site is produced. These measurements are an independent experiment by this site. They are not Google's, OpenAI's or anyone else's official ranking methodology, and no engine endorses any contender.

Test environment

  • Primary market: United States, in English; Brazil is measured in parallel for cross-index comparison.
  • Sessions: logged out, in a fresh incognito window per prompt, with no intentional personalization.
  • Locale: US runs use the engine set to English with a United States location; BR runs use a Brazil location; the prompt text never changes between countries.
  • Every observation records its exact query, engine, country and ISO date, with a source note per row and a screenshot where available.
  • These are manual single observations, not aggregated sampling: one run per prompt, per engine, per country, per week. A single answer can vary between runs; the log records what one logged-out session saw on one date and does not average variance away.

Engines

Weekly series (from 2026-10-05): Google AI Overviews, ChatGPT, Perplexity and Gemini. The September 2026 experiment window additionally recorded Google organic rankings and the Bing answer box; those observations remain in the dataset and the scoreboard above.

Publication rules

  • Every result is published, favorable or not — the September record includes the ranking loss and the Wikidata rejection.
  • No row is invented, estimated or backfilled; an unmeasured cell reads "Not measured".
  • Rows are append-only; published observations are never rewritten.
  • All data ships as versioned CSV and JSON under CC BY 4.0.
